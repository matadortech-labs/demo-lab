# Keyfactor Command Use-Case Demos

Reference implementations demonstrating certificate lifecycle automation,
machine identity management, and application-centric assurance using Keyfactor
Command and Universal Orchestrator.

## Demos

### [NGINX One-Click Certificate Renewal](./NGINX-one-click-renewal/)

Operator-driven certificate renewal and deployment for NGINX.

### [NGINX Certificate Renewal Assurance](./nginx-certificate-renewal-assurance/)

Closed-loop certificate renewal assurance that verifies the application endpoint
is actually serving the renewed certificate and records validation evidence in
Keyfactor Command.
